# Support the project

I have been asked more than once why there is no "buy me a coffee" button or sponsoring option on this project. The answer is that I do not want Task Observer to be a paid project. I want it to be community-driven and free for everyone, which is what it already is. Plenty of contributors have made it far better than it could ever have been without them, and every one of them is credited in the commit history and in the release notes.

So if you want to support the project, the first thing to do is join us: open an issue when something misfires, send a pull request when you have fixed it, and report what happened when you tried it in an environment I do not use. That is where most of the improvements come from.

If you maintain open-source skills with Task Observer, list them in the [Open Skill Library](OPEN-SKILL-LIBRARY.md). That is another way to contribute.

## What is still missing: distribution

One thing the project lacks is reach. It is not backed by a large organisation or by a well-known individual with a huge audience. It is just me and you, the people who use it. So, instead of buying me a coffee or sponsoring the project, the best thing you can do is help it reach more people:

- If you know someone who would benefit from Task Observer, tell them about it.
- If you have an audience of your own, tell them about it.
- If you know someone who has an audience, tell them, so they can spread the word.

Public recommendations are included in the README under [Recommended by](README.md#recommended-by) and [Listed in](README.md#listed-in). Send me the link, or submit a pull request that adds it in the same format as the existing entries, and it goes in.

Thank you.
